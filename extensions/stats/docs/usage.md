# 使用

## /stats

```text
/stats
```

命令要求交互式界面；扫描时状态栏显示进度，扫描结束后清除状态（[入口](../index.ts)、[测试](../index.test.ts)）。

默认项目会话目录对应的扫描范围为 `<agent-dir>/sessions` 下的全部项目；会话管理器使用其他目录时，扫描范围为该目录及其子目录（[入口](../index.ts)、[扫描实现](../core.ts)）。

统计读取 JSONL（每行一个 JSON 记录）会话文件，累计输入、输出、缓存读取和缓存写入 Token，费用取会话记录中的总费用；复制到分叉会话的相同记录去重（[实现](../core.ts)、[测试](../core.test.ts)）。

助手记录按服务商和模型聚合，响应模型名优先于请求模型名；工具结果、压缩和分支摘要的用量归入 `Tools/summaries`，模型信息不全的助手记录归入 `Unknown model`（[实现](../core.ts)、[测试](../core.test.ts)）。

### 终端面板

终端用户界面（TUI）先展示今日、本月和累计 Token，以及当前年的每日热力图；摘要按报告生成时的本地日期计算，切换年份保留摘要（[报告](../report.ts)、[面板测试](../tui.test.ts)）。

| 操作 | 结果 |
|---|---|
| ← / → | 向前 / 向后移动一周 |
| ↑ / ↓ | 向前 / 向后移动一天 |
| `[` / `]` | 上一年 / 下一年 |
| Pi 的翻页操作键（默认 PgUp / PgDn） | 上一年 / 下一年 |
| Enter 或 Pi 的确认操作键 | 关闭面板后生成并打开 HTML 报告 |
| Esc 或 Pi 的取消操作键 | 关闭面板 |
| 左键点击日期格 | 选中日期 |
| 左键点击年份两侧箭头 | 切换年份 |
| 左键点击「查看详情」 | 打开 HTML 报告 |

键盘与鼠标操作见 [tui.ts](../tui.ts) 和[测试](../tui.test.ts)；Pi 操作键使用当前键绑定。

选中日期展示精确 Token 数和两位小数费用；跨年时保留月日，闰日切到平年落在二月末（[实现](../tui.ts)、[测试](../tui.test.ts)）。

热力图以周日为每周起点，每格占一列、间隔一列；窄窗口随选中日期平移，面板高度最多 15 行（[日历](../calendar.ts)、[面板](../tui.ts)、[测试](../tui.test.ts)）。

### 浏览器报告

远程过程调用（RPC）界面直接生成并打开 HTML 报告；TUI 通过「查看详情」进入，取消面板则结束流程（[入口](../index.ts)、[测试](../index.test.ts)）。

报告是本次扫描的静态快照，包含累计、最近 30 天和最近 24 小时的 Token 与费用，时间窗口以生成时刻向前滚动（[报告](../report.ts)、[测试](../html.test.ts)）。

模型下拉框过滤摘要和每日热力图，模型条形图保留全部模型；热力图覆盖生成日期所在周及此前 52 周，悬停日期格查看用量和费用（[模板](../template.html)）。

HTML 写入系统临时目录中的 `pi-stats-<随机后缀>/stats.html`，成功打开后通知文件路径；打开失败时通知错误（[HTML 实现](../html.ts)、[入口](../index.ts)、[测试](../html.test.ts)）。
