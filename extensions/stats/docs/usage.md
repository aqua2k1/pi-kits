# 使用

## /stats

在 Pi 交互界面输入：

```text
/stats
```

扫描时状态栏显示进度，扫描结束后清除状态；终端界面展示面板，远程调用界面（RPC）直接打开浏览器报告。

### 统计范围与口径

默认项目会话目录对应的扫描范围为 `<agent-dir>/sessions` 下的全部项目；会话管理器使用其他目录时，扫描该目录及其子目录。

统计读取 JSONL（每行一个 JSON 记录）会话文件，累计输入、输出、缓存读取和缓存写入 Token，费用取记录中的总费用。带有记录 ID、身份与用量内容均相同的复制记录跨文件去重；相同 ID 的不同用量分别累计。

助手记录按服务商和模型聚合，响应模型名优先于请求模型名；带用量的工具结果、压缩和分支摘要归入 `Tools/summaries`，模型信息不全的助手记录归入 `Unknown model`。

无效或负数的用量字段按零计算；日期无效的记录仍进入累计和模型统计。扫描跳过损坏的 JSON 行，文件读取失败后继续扫描其余文件。

### 终端面板

面板展示今日、本月和累计 Token，以及当前年的每日热力图；摘要按报告生成时的本地日期计算，切换年份保留摘要。

| 操作 | 结果 |
|---|---|
| ← / → | 向前 / 向后移动一周，在当前年内到边界停止 |
| Pi 的上移 / 下移键（默认 ↑ / ↓） | 向前 / 向后移动一天，在当前年内到边界停止 |
| `[` / `]` | 上一年 / 下一年 |
| Pi 的翻页键（默认 PgUp / PgDn） | 上一年 / 下一年 |
| Enter 或 Pi 的确认键 | 关闭面板后生成并打开 HTML 报告 |
| Esc 或 Pi 的取消键 | 关闭面板 |
| 左键点击日期格 | 选中日期 |
| 左键点击年份两侧箭头 | 切换年份 |
| 左键点击「查看详情」 | 打开 HTML 报告 |

选中日期展示精确 Token 数和两位小数费用；跨年时保留月日，闰日切到平年落在二月末。年份范围为 1–9999。

热力图以周日为每周起点；窄窗口随选中日期平移，面板高度最多 15 行。全屏终端提供鼠标点击，常规终端使用键盘。

### 浏览器报告

报告是本次扫描的静态快照，包含累计、最近 30 天和最近 24 小时的 Token 与费用，时间窗口以生成时刻向前滚动，包含起止时刻。

模型下拉框过滤摘要和每日热力图，模型条形图保留全部模型；热力图覆盖生成日期所在周及此前 52 周，悬停日期格查看用量和费用。

HTML 写入系统临时目录中的 `pi-stats-<随机后缀>/stats.html`，由系统默认应用打开；成功后通知文件路径，打开失败时通知错误。
