# stats

`/stats` 聚合本地会话的 Token（输入、输出、缓存读取与缓存写入之和）和费用，展示终端面板及浏览器报告。

## 安装

```sh
pi install https://github.com/aqua2k1/pi-kits.git
```

仓库包通过 [Pi 清单](../../package.json)加载本扩展。

## 快速开始

在 Pi 交互界面输入：

```text
/stats
```

终端交互界面（TUI）展示统计面板；按 Enter 打开浏览器报告。
