# 使用

## /handoff

命令从当前叶节点（会话当前分支末端的条目）创建会话副本，在副本中压缩内容为交接摘要；流程见 [index.ts](../index.ts)。

```text
/handoff
/handoff <交接重点>
```

| 参数 | 说明 |
|---|---|
| `focus` | 可选自由文本，去除首尾空白后追加到摘要指令，指定交接重点 |

1. 等待当前任务空闲。
2. 读取当前叶节点和会话文件；空会话或未保存会话显示警告并结束。
3. 从叶节点创建副本，在副本上下文中调用会话压缩。
4. 压缩完成后显示交接会话文件路径；路径缺失时显示 `(memory session)`。

压缩指令要求摘要保留目标、约束、进展、关键决策、阻塞、下一步、已读取文件和已修改文件，并要求省略完整对话记录与差异、隐去敏感信息。指令原文见 [index.ts](../index.ts) 的 `HANDOFF_INSTRUCTIONS`。
