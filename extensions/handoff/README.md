# handoff

`/handoff` 从当前会话创建副本，并在副本中压缩生成交接摘要。

## 安装

```sh
pi install https://github.com/aqua2k1/pi-kits.git
```

## 快速开始

在已有内容且已保存的 Pi 会话中输入：

```text
/handoff
```

命令等待当前任务空闲，从当前分支末端创建会话副本，压缩完成后显示交接会话路径。
空会话或未保存的会话显示警告并结束；副本路径缺失时显示 `(memory session)`。

## 使用

指定交接重点：

```text
/handoff <交接重点>
```

| 参数 | 说明 |
|---|---|
| 交接重点 | 可选自由文本，去除首尾空白后加入摘要指令 |

将占位值替换为交接重点。摘要指令要求保留目标、约束、进展、关键决策、阻塞、下一步、已读文件和已改文件，并要求省略完整对话及差异、隐去敏感信息。
