# handoff

## 功能简介

通过 `/handoff [focus]` 从当前会话的叶节点创建独立的会话副本，并在副本中生成面向下一位 agent 的精简交接摘要。原会话不会被压缩；完成后会通知新会话文件路径。

## 使用方法

```text
/handoff
/handoff 优先说明未完成事项、当前阻塞和下一步
```

`focus` 是可选的自由文本，会追加到压缩指令中，用于强调需要保留的内容。交接指令要求摘要保留目标、约束、进展、关键决策、阻塞、下一步、已读取文件和已修改文件；不复述完整 transcript 或 diff，并尽量脱敏敏感信息。

## 架构

```mermaid
flowchart LR
  A["当前会话"] --> B["等待空闲"]
  B --> C["检查会话状态"]
  C --> D["从当前叶节点 fork"]
  D --> E["在副本中 compact"]
  E --> F["通知会话文件路径"]
```

`index.ts` 依次等待当前任务结束、确认会话非空且已保存，从当前叶节点分叉，再只在新会话中执行压缩。

## 注意事项

- 当前会话正在生成回复时，命令会先等待其进入空闲状态。
- 空会话或未保存的会话无法交接，并会显示警告。
- 摘要由模型生成，脱敏和信息保留应在交给下一位 agent 前人工核对。
- 本扩展没有专属配置，不读取 `pi-kits.json`；加载扩展后即可使用 `/handoff`。
