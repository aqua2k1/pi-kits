# 使用

## /preview

选择当前会话分支的一轮回复并打开只读预览。

```text
/preview
/preview --thinking
/preview --help
```

| 参数 | 说明 |
|---|---|
| 无参数 | 选择回复，预览文本块 |
| `--thinking` | 加入 thinking（模型思考）块，每行使用 Markdown 引用前缀 |
| `help`、`--help`、`-h` | 显示命令帮助 |

一轮回复指两条用户消息之间（或分支起止边界内）的所有助手消息。列表按最新优先显示，编号按时间从旧到新排列；标签使用首个非空文本行，超过 50 个字符时追加省略号。

选择回复后，各助手消息的文本以空行拼接。取消选择会结束流程。

命令在空闲的 TUI（Pi 交互式终端界面）中打开预览；任务仍在运行、尚无回复或所选回复内容为空时显示提示。未知参数显示错误和帮助。

编辑器选择见[配置](configuration.md)；临时预览资源和终端交接见[共享库](../../../shared/README.md)。

## Alt+P

在空闲的 TUI 中按下：

```text
Alt+P
```

快捷键直接预览最新一轮回复的文本块，跳过回复选择。
