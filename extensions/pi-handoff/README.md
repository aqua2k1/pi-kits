# handoff

`/handoff` 将当前会话整理为 Markdown 交接文档，`/handoff-open` 在新会话中加载交接上下文。

## 安装

```sh
pi install https://github.com/aqua2k1/pi-kits.git
```

## 快速开始

在已有内容的 Pi 会话中输入：

```text
/handoff
```

命令等待当前任务空闲，将整理指令发送到当前会话，由当前 agent 使用现有文件工具生成或更新文档，并在确认保存后报告交接 ID、路径和读取命令。
会话继续保留，用户可以继续要求调整交接内容，并自行决定何时结束。空会话显示警告。

## 使用

指定交接重点：

```text
/handoff <交接重点>
```

| 参数 | 说明 |
|---|---|
| 交接重点 | 可选自由文本，去除首尾空白后加入摘要指令 |

将占位值替换为下一会话的重点；所有参数均作为自由文本处理。

文档保存在 Pi 实际 agent-dir 下的 `handoffs/<id>.md`。同一来源会话更新同一文件，ID 保持不变。用户可以直接编辑 Markdown 正文，保留首行元数据；再次执行命令时，扩展将当前版本备份为同目录的隐藏 `.bak` 文件，整理指令要求 agent 读取最新文件、保留手动调整，并在写入前重新检查外部修改。

文档按以下章节组织：下一会话目标、当前状态、关键上下文、相关资料、下一步、Suggested skills。已有规格、计划、提交和 diff 只引用，验证结果区分事实与推测，敏感信息按指令脱敏。

### 加载交接

自行开启新会话后输入：

```text
/handoff-open
/handoff-open <id>
```

无参数时，选择器列出当前项目的交接文档，按文件更新时间倒序排列；指定 ID 时直接读取。加载时读取磁盘最新内容，文件保留原归属且不删除。

交接内容完整加入当前会话，不触发模型回复或自动执行下一步。会话消息默认折叠显示 ID、标题和目标，使用 Pi 原生展开操作查看完整 Markdown。

新会话执行 `/handoff` 会创建自己的交接文档，不覆盖加载的上游文档。
