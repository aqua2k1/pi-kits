# 使用

## /usage

在 Pi 中选择已配置认证的 `deepseek` 或 `openai-codex` 服务商模型，然后输入：

```text
/usage
```

命令立即刷新当前主会话模型对应的数据源，并通知最新显示行；达到预警阈值时通知使用警告级别。

| 主会话模型的服务商标识 | 编辑器下方的显示内容 |
|---|---|
| `deepseek` | 各币种余额；任一币种余额低于 20 时显示警告色 |
| `openai-codex` | ChatGPT 套餐、各窗口已用百分比和重置倒计时；任一窗口达到 80% 时显示警告色 |

ChatGPT 窗口标签按周期长度匹配为 `5h`、`daily`、`weekly`、`monthly`、`annual`，其他周期显示 `limit`。多个窗口同时展示，套餐字段缺失时省略套餐名称。

倒计时保留两个单位：周期短于一天的窗口显示小时和分钟，其余显示天和小时；剩余分钟四舍五入后小于等于零时省略倒计时。倒计时随用量刷新更新。

会话启动和模型选择触发刷新，并启动定时刷新；默认每 10 分钟刷新一次，获取凭据后的请求默认在 15 秒后取消。间隔与超时见[配置](configuration.md)。

认证来自 Pi 模型注册表；凭据缺失时隐藏组件并停止轮询，选择模型或重新启动会话可重新触发认证读取。切换离开表中服务商时隐藏组件并停止轮询。

刷新失败时，已有成功缓存显示 `(stale)`，表示保留的旧结果；没有缓存时显示占位行和错误简因。接口返回空数据时显示占位行并保留缓存。

ChatGPT 返回 HTTP 401 时清除其缓存，并提示重新登录：

```text
/login openai-codex
```

登录后重新选择模型，或等待下一次刷新，再查看用量。
