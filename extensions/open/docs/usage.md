# 使用

## /open

用系统默认应用打开指定目标。

```text
/open <文件路径>
/open <网址>
/open <目录路径>
```

将占位值替换为实际目标。

| 参数 | 说明 |
|---|---|
| 目标 | 文件路径、URL（网址）或目录路径 |

命令显示启动结果，成功使用信息提示，失败使用警告提示；空参数显示用法，本地目标不存在时显示目标路径。

目标解析与平台启动见[共享实现](../../../shared/desktop-open.ts)。

## open 工具

模型通过工具参数指定目标。

```json
{
  "target": "<文件路径>"
}
```

将占位值替换为实际目标；入口与命令共用同一打开流程。

| 参数 | 说明 |
|---|---|
| `target` | 要打开的文件路径、网址或目录路径 |

工具返回文本结果，并在 `details` 中提供 `ok` 和 `message`；结果渲染显示 `opened` 或 `error` 状态。
