# open

`/open` 和模型工具 `open` 用系统默认应用打开文件、URL（网址）或目录。

## 安装

```sh
pi install https://github.com/aqua2k1/pi-kits.git
```

仓库包通过 [Pi 清单](../../package.json)加载本扩展。

## 快速开始

```text
/open <目录路径>
```

将占位值替换为已有目录路径，命令请求系统默认应用打开该目录，并显示启动结果。
