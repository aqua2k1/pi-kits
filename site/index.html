01 / SUBAGENT

把任务交给独立会话。

为代码探索、审阅等独立工作创建 Pi 或 Codex 任务，在父会话中获取结果，也能通过 Herdr 打开可交互的原生终端。

独立任务

任务进入队列，由独立后端执行；支持后台运行和结果等待。

原生交互

通过 Herdr 查看并操作实际会话，而不只读取最终回复。

会话续跑

保留会话后继续交付任务，区分任务轮次与会话连接状态。

架构与设计取舍
Pi 工具入口→管理器
队列 / 轮次 / 结果→Pi / Codex 后端↔Herdr
终端 / 视图

管理器负责调度和资源生命周期，后端通过统一事件报告执行情况，展示层订阅状态快照。任务是否完成与会话是否空闲分别记录，避免把完成结果等同于会话已经释放。

运行条件：安装 Herdr，在 Herdr 内启动 Pi，并配置 subagent.mux: "herdr"。Pi 和 Codex 后端分别需要对应的可执行程序。

02 / CANVAS NOTE

把输出组织成文档。

在浏览器中阅读 Pi 生成的文字、图表、公式和代码，选择多个内容块发送反馈，并导出 PDF 或离线 HTML。

结构化内容

以页面和内容块组织正文，使用稳定 ID 定位需要更新或反馈的内容。

实时同步

落盘后推送操作增量，浏览器首次连接与重连时通过完整快照恢复。

带上下文的反馈

反馈保存所选块的版本与快照，再交回 Pi，保留用户实际引用的内容。

架构与设计取舍
Pi 工具→文档存储
JSON / 原子写入→HTTP / WebSocket→浏览器文档

JSON 文件是文档的权威状态，操作增量只用于实时同步，不作为持久化事件日志。浏览器回复先校验版本并保存反馈快照，再交付 Pi；过期反馈保留输入并拒绝提交。

文档保存在项目的 docs/canvas-notes/。在线同步与反馈由本地 Pi 服务提供；导出的单文件 HTML 可离线阅读。本站仅展示产品，不运行插件服务。

GET STARTED

在 Pi 中使用。

需要 Pi 和 Node.js ≥ 22.19。安装后通过 pi config 选择扩展。

pi install https://github.com/aqua2k1/pi-kits.git

Subagent

在 ~/.pi/agent/pi-kits.json 中配置：

{
  "subagent": { "mux": "herdr" }
}

在 Herdr 内启动 Pi，重新加载扩展后，让 Agent 委派任务。使用 /subagent:views 查看任务视图。

Canvas Note

重新加载扩展后，在 Pi 中输入：

/canvas-note 分析当前项目架构，并绘制模块关系图

首次插入内容时启动文档服务，访问地址显示在 Pi 状态栏。
